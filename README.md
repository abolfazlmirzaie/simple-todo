# ✅ TODO API with Django REST Framework

A simple TODO application built with **Django REST Framework**, **Postgres**, and **Docker**.  
It supports user authentication (JWT + Session), CRUD operations for tasks, and auto-generated API documentation with **drf-spectacular**.

---

## 🚀 How to Run with Docker Compose

1. Make sure you have **Docker** and **Docker Compose** installed.
2. Clone this repository and go to the project folder:
   ```bash
   git clone <your-repo-url>
   cd <your-project-folder>

   ## Build and start the containers:
   docker-compose up --build
   ###
   
   ### The Django server will be available at:
   http://localhost:8000
   ###
